# START_HERE — Reprise minimale

FileTopo est le projet public officiel. La version 0.1 alpha reste un prototype
historique utile, mais elle ne représente pas encore le produit demandé. La
reconstruction se fait dans le dépôt et l'historique existants, sans effacer le
prototype.

## Ordre obligatoire

1. [AGENTS.md](../../AGENTS.md) ou [CLAUDE.md](../../CLAUDE.md);
2. ce fichier;
3. [CURRENT_STATE.md](CURRENT_STATE.md);
4. [NEXT_ACTION.md](NEXT_ACTION.md);
5. le fichier de la tâche active ou approuvée;
6. seulement ensuite les fichiers supplémentaires nommés par cette tâche.

## Règles immédiates

- Vérifier Git avant toute modification.
- Au plus une tâche IN_PROGRESS.
- Utiliser uniquement des données synthétiques.
- Ne jamais accéder à l'interface privée de référence.
- Ne jamais modifier les documents analysés.
- Une affirmation sans preuve doit être marquée non testée.
- IMPLEMENTED attend une vérification indépendante avant VERIFIED.

Pour une reprise après interruption, suivre [RECOVERY.md](RECOVERY.md).
