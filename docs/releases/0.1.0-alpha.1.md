# FileTopo 0.1.0-alpha.1 — candidate release notes

**Status:** unsigned, unpublished local candidate.
**Prepared and independently verified:** 2026-08-26.

## Highlights

- Several independent local collections with a name, colour and icon.
- Native folder selection and explicitly triggered indexing.
- Metadata-only scanning, cancellable, with no partial index.
- PixiJS/WebGL topographic map, relief fallback, pagination and level of detail.
- Search, filtering by kind, online-only files and unseen items.
- An accessible synchronised list and a French/English interface that follows
  the preferred system language, with English as the fallback.
- Explicit, confined reveal in Windows File Explorer.
- A local SQLite index, rebuildable and stored outside the collections.

## Local verification

The candidate passed 36 interface tests, 13 Rust tests, TypeScript, Vite,
strict Clippy in both debug and release profiles, the dependency audit and a
clean Windows/NSIS build. Synthetic measurements at 100,000 items are recorded
in `docs/performance/phase-4-mvp-measurements.md`.

## Known limits

- Windows 10/11 only; macOS and Linux are not validated.
- Full index rebuilds; incremental watching is not delivered.
- No application-level index encryption and no built-in erasure of application
  data.
- No network, account, synchronisation, AI, OCR or automatic updates.
- The synthetic fixture button exists in development builds only.
- FileTopo remains a working name with no exhaustive legal clearance.

## Publication decision

Publish `v0.1.0-alpha.1` as a **source-only prerelease**. Do not upload the
unsigned executable or installer. GitHub may provide automatically generated
source archives for the tagged commit.
